# Everyday League

A browser coach for controlled arm raises and squats. It scores how you move, not how fast you finish.

Experimental prototype. Scores depend on the camera and are not a clinical assessment.

## Run

```sh
npm install
npm run dev
```

Open http://localhost:3000.

Demo Mode needs no camera. For voice, the leaderboard, or next-workout ideas, copy `.env.example` to `.env.local`.
